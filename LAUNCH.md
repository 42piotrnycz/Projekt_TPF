## Konfiguracja środowiska

### Wymagania
- **Node.js** >= 16.x
- **npm** lub **yarn**

```bash
npm install
```
```bash
npm run dev
```
Aplikacja dostępna na: `http://localhost:3000`

```bash
npm run build
```

```bash
npm run lint


| Komenda | Opis |
|---------|------|
| `npm run dev` | Dev server z hot reload |
| `npm run build` | Build dla produkcji |
| `npm run preview` | Preview zbudowanego projektu |
| `npm run lint` | Sprawdzenie kodu ESLint'em |
| `npm install` | Instalacja zależności |
