# React + TypeScript + Vite

Projekt React ze wsparciem TypeScript i Vite'a.

## 🚀 Szybki start

### Instalacja zależności
```bash
npm install
```

### Serwer deweloperski
```bash
npm run dev
```

Aplikacja otworzy się na `http://localhost:3000` z hot-reload'em.

### Build dla produkcji
```bash
npm run build
```

### Preview buildu
```bash
npm run preview
```

### Linting
```bash
npm run lint
```

## 📁 Struktura projektu

```
.
├── src/
│   ├── App.tsx          # Główny komponent
│   ├── App.css          # Style App
│   ├── index.css        # Globalne style
│   └── main.tsx         # Entry point
├── index.html           # HTML template
├── vite.config.ts       # Konfiguracja Vite
├── tsconfig.json        # Konfiguracja TypeScript
├── eslint.config.js     # Konfiguracja ESLint
└── package.json         # Zależności i skrypty
```

## 🛠️ Technologie

- **React 18** - UI library
- **TypeScript** - Typowy JavaScript
- **Vite** - Bundler i dev server
- **ESLint** - Linter kodu
- **CSS** - Stylowanie

Możesz zacząć edytować plik `src/App.tsx` i zobaczyć zmiany na żywo!
